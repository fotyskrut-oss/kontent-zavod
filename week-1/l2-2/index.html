Урок 2.2. Как ставить задачу агенту

Агент делает больше, чем чат, — и ошибается тоже масштабнее. Нечёткая задача в чате даёт плохой абзац. Нечёткая задача агенту даёт 20 файлов не того. В этом уроке — как ставить задачи так, чтобы результат получался с первого раза.

Структура хорошей задачи

  1. Цель — зачем это нужно: «чтобы администратор мог выкладывать посты без меня».
  2. Результат — что должно появиться: файлы, их названия, формат.
  3. Исходники — откуда брать данные: «из passport.md», «из папки photos».
  4. Ограничения — чего не делать: «не трогай папку archive», «ничего не удаляй».
  5. Критерий готовности — как понять, что всё готово: «в таблице 14 строк, у каждого поста есть картинка».

Пример: до и после

До:

Сделай контент на неделю.

После:

Цель: готовый контент на неделю для VK и Telegram, чтобы администратор
мог выложить без меня.
Исходники: passport.md (паспорт дела), faq.md (частые вопросы родителей).
Результат:
- папка week_11 с файлами post_1.md ... post_3.md (понедельник, среда, пятница);
- в каждом файле: текст поста до 900 знаков и промпт для обложки;
- файл plan.md — таблица: день, площадка, тема, время публикации.
Ограничения: соблюдай блок «Ограничения» из паспорта, не меняй другие файлы.
Готово, когда: 3 поста и план лежат в папке, темы не повторяются.
Сначала покажи 3 темы — я утвержу, потом пиши.

Сначала план, потом работа

Для любой задачи длиннее пары шагов просите: «Сначала покажи план, ничего не делай». Вы проверяете план за минуту и ловите ошибку до того, как на неё потрачено время. В приложении есть и специальный режим планирования, в котором Claude сначала изучает и предлагает, и только потом меняет файлы.

Маленькие шаги

Не просите «сделай мне весь контент-завод». Делите на шаги и проверяйте каждый:

  1. Собрать частые вопросы → проверить.
  2. Составить список тем → утвердить.
  3. Написать 3 поста → поправить тон.
  4. Написать остальные по образцу.

Если ошибка на шаге 2, вы исправляете один список, а не 20 готовых постов.

Как проверять результат

  • Откройте файлы сами. Не верьте на слово «готово» — посмотрите, что там.
  • Попросите отчёт: «Перечисли, какие файлы создал и что изменил».
  • Попросите самопроверку: «Проверь каждый пост по блоку Ограничения и скажи, где есть нарушения».
  • Видео и картинки смотрите глазами целиком, до публикации.

Как давать правки

  • Конкретно: не «плохо», а «в post_2 слишком официально, перепиши как разговор с мамой на кухне».
  • Одна правка — одно сообщение, если правки разные по смыслу.
  • Если правка постоянная — «запомни это и добавь в CLAUDE.md» (следующий урок).

Задачи для контента, которые хорошо делает агент

  • «Вот выгрузка вопросов из личных сообщений (без имён). Сгруппируй по темам и составь faq.md».
  • «Из faq.md сделай 20 тем для постов и распредели по календарю».
  • «Переименуй фото в папке photos по дате и сделай их квадратные копии для ленты».
  • «Переделай пост post_1.md в сценарий ролика на 30 секунд и текст для сторис».
  • «Сделай страницу «О нас» для сайта в формате HTML по паспорту».

Типичные ошибки

  • Одна огромная задача без плана и промежуточных проверок.
  • Нет критерия готовности — агент останавливается раньше или делает лишнее.
  • Правки «не то, переделай» без объяснения, что именно не так.
  • Публикация без просмотра.

Практика (40 минут)

  1. Напишите задачу по структуре «цель — исходники — результат — ограничения — готово, когда»: контент на следующую неделю.
  2. Попросите сначала план. Поправьте его хотя бы в одном месте.
  3. Доведите до результата, проверьте файлы сами, дайте 2 конкретные правки.

В чат: текст вашей задачи и скриншот папки с результатом.

Проверьте себя

  1. Из каких 5 частей состоит хорошая задача агенту?
  2. Зачем просить сначала план?
  3. Как правильно давать правки?
