Урок 2.3. CLAUDE.md и скиллы

Каждая новая сессия Claude Code начинается с чистого листа: он не помнит, о чём вы договаривались вчера. Чтобы не объяснять всё заново, есть два инструмента: CLAUDE.md — правила проекта, и скиллы — готовые инструкции для повторяющихся задач.

CLAUDE.md — память проекта

Это обычный текстовый файл в корне папки проекта. Claude Code читает его автоматически в начале каждой сессии. Аналогия: инструкция для нового сотрудника, которую он перечитывает каждое утро.

Что туда писать

  • Кто вы и чем занимаетесь (или ссылка на passport.md).
  • Структура папок: что где лежит.
  • Правила тона и оформления.
  • Запреты: что нельзя делать никогда.
  • Рабочие привычки: «сначала показывай план», «пиши по-русски».

Пример CLAUDE.md для детского центра

# Контент центра «[Название]»

## О нас
Полный паспорт — в passport.md. Прочитай его перед любой задачей про тексты.

## Папки
- posts/ — готовые посты, по неделям (week_45, week_46...)
- photos/ — фото с согласием родителей. Других фото не использовать.
- prompts/ — библиотека промптов

## Тон
Спокойный, тёплый, на «вы». Без эмодзи в первой строке.

## Никогда
- не обещать результат («заговорит», «вылечим»);
- не упоминать имена и диагнозы детей;
- не удалять файлы, только переносить в archive/.

## Как работаем
Сначала план, потом работа. В конце — список созданных файлов.

Как его создать

Не пишите с нуля. Попросите: «Создай CLAUDE.md для этого проекта. Посмотри папки, прочитай passport.md и задай мне вопросы про правила и запреты». Потом дополняйте его каждый раз, когда повторяете одну и ту же правку: «Добавь это правило в CLAUDE.md».

Правило короткого файла

CLAUDE.md читается каждый раз, поэтому держите его коротким (1–2 экрана). Большие документы (паспорт, стиль-гайд) — в отдельных файлах, а в CLAUDE.md — ссылки на них.

Скиллы — готовые умения

Скилл — это папка с инструкцией (файл SKILL.md) и, если нужно, примерами, шаблонами и скриптами. В отличие от CLAUDE.md он загружается только когда нужен: Claude видит короткое описание скилла и сам решает его открыть, или вы вызываете его командой со слэшем.

Пример из нашей работы

Мы пользуемся скиллом для motion-роликов: в нём описано, как придумать раскадровку, каким должен быть ритм, как проверить готовое видео. Когда мы просим «сделай анимацию», Claude открывает скилл и работает по нему — без наших объяснений.

Как сделать свой скилл

  1. Найдите задачу, которую делаете регулярно и объясняете одно и то же: «пост из фото с занятия», «недельный контент-план».
  2. Сделайте её один раз вместе с Claude до хорошего результата.
  3. Попросите: «Сделай из этого скилл, чтобы в следующий раз ты делал так же без моих объяснений». У Claude есть встроенный помощник для создания скиллов.
  4. Проверьте в новой сессии: дайте короткую задачу и посмотрите, подхватился ли скилл.
  5. Дорабатывайте по ходу: «Добавь в скилл, что…».

Хорошее описание скилла говорит, когда его использовать: «Используй, когда нужно сделать пост из фото с занятия». По этой фразе Claude и решает, открывать ли его.

Типичные ошибки

  • CLAUDE.md на 10 страниц — важное тонет среди неважного.
  • Расплывчатые правила: «пиши хорошо» вместо «до 900 знаков, на вы».
  • Скилл без понятного описания — Claude его не находит.
  • Устанавливать чужие скиллы из непроверенных источников, не прочитав: скилл может содержать скрипты.

Практика (40 минут)

  1. Попросите Claude Code создать CLAUDE.md для вашего проекта. Проверьте, что там есть блок «Никогда».
  2. Откройте новую сессию, попросите пост без пояснений — тон и правила должны соблюдаться сами.
  3. Сделайте первый скилл «Пост из фото с занятия» (или другая ваша повторяющаяся задача) и проверьте его в новой сессии.

В чат: текст CLAUDE.md и название + описание скилла.

  3. Какая фраза превращает удачную работу в скилл?
  4. Что должно быть в описании скилла?
